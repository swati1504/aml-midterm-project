## Running in Colab
1. Open `midterm/part1.ipynb` in Colab (File → Open notebook → GitHub tab → this repo).
2. Run all. The first cell installs `rdkit` and asks you to upload the Part 1 Kaggle zip
   (`cs-5785-midterm-2026-clinical-trial-reason-prediction.zip`). Alternatively, put the CSVs in `./data/`.
3. Outputs land in `figures/` and `outputs/`.
