# CS5785 Midterm (Fall 2026) — Clinical-trial stopping reasons & outcomes

```
midterm/
  part1.ipynb                     # Part 1: semi-supervised reason labeling (runs top to bottom, ~5 min CPU)
  part2.ipynb                     # Part 2: per-phase outcome prediction + error analysis by reason (~50 min CPU)
  figures/                        # fig*.png = Part 1, p2_fig*.png = Part 2 (PNG, 200 dpi), generated by the notebooks
  outputs/
    part1_submission.csv          # Kaggle Part 1 submission (primary)
    part1_submission_alt_em.csv   # alternate: same model + EM prior-shift correction (14/312 rows differ)
    part1_reason_labels_all_trials.csv   # HANDOFF from Part 1 to Part 2 (reason labels + true/predicted source)
    part1_results_summary.csv     # Part 1 main results table
    exp*.csv                      # raw results of every Part 1 experiment
    part2_submission.csv          # Kaggle Part 2 submission (primary: stacked ensemble + year trend)
    part2_submission_alt_noyear.csv      # alternate: same stack without the start-year trend
    p2_*.csv                      # Part 2 results, per-phase metrics, error-by-reason tables, temporal holdout
PART1_NOTES_FOR_REPORT.md         # Part 1 numbers, methods & insights for the write-up
PART2_NOTES_FOR_REPORT.md         # Part 2 numbers, methods & insights for the write-up
```

## Running in Colab
1. Open the notebook in Colab (File → Open notebook → GitHub tab → this repo).
2. Run all. The first cell installs `rdkit` and asks you to upload the Kaggle zip
   (Part 1: `cs-5785-midterm-2026-clinical-trial-reason-prediction.zip`; Part 2: the zip with `outcome_*.csv`).
   Alternatively, put the CSVs in `./data/` (or point `P1_DATA_DIR` / `P2_DATA_DIR` at them).
3. `part2.ipynb` also reads `outputs/part1_reason_labels_all_trials.csv` (committed) for the error analysis.
4. Outputs land in `figures/` and `outputs/`.

Note: if the repo lives in iCloud Drive, macOS may evict `data/*.csv` to placeholders; set `P2_DATA_DIR` to a local copy.
